## 💫 About Me

I'm a Cloud Engineer based in Lagos, Nigeria, focused on AWS infrastructure, serverless applications and deployment automation.

I've worked on CI/CD pipelines, infrastructure as code (Terraform and CloudFormation), containerised workloads on ECS, EKS and Fargate, and CloudWatch monitoring. My backend background covers ASP.NET Core, REST APIs, JWT authentication and Postgres/SQL Server.

Outside my cloud work, I build and maintain web apps for small businesses, including a point-of-sale and inventory system that a retail shop in Nigeria uses daily. It's built with Next.js and Supabase, with money-handling logic in Postgres functions so stock, payments and audit logs update together.

- 🌱 **Currently:** deepening my Terraform, Kubernetes and serverless design skills
